# OpenKB CLI API Reference

Command line interface specifications for `@todo-labs/openkb`.

## `openkb init [dir]`

Scaffolds a complete OpenKB documentation repository in the target directory.

<ParamField path="dir" type="string" default=".">
  The directory path where starter documentation files should be created.
</ParamField>

---

## `openkb dev`

Starts the local Astro live-reloading preview server.

<ParamField query="port" type="number" default="3000">
  Port number to listen on. Defaults to 3000.
</ParamField>

---

## `openkb build`

Compiles documentation into 100% static HTML/CSS/JS and builds the Pagefind search index.

<ResponseField name="dist/" type="directory" required={true}>
  Contains all static HTML files, JavaScript bundles, CSS stylesheets, and precomputed search indexes.
</ResponseField>

---

## `openkb generate`

Synthesizes living OKF concept documentation from codebase AST and git history using Gemini 3.7 Flash.

<ParamField query="init" type="boolean" default="false">
  Performs full initial codebase analysis and documentation creation.
</ParamField>

<ParamField query="update" type="boolean" default="false">
  Performs incremental documentation update based on Git diffs.
</ParamField>

<ParamField query="model" type="string" default="google/gemini-2.5-flash">
  OpenRouter model identifier for synthesis.
</ParamField>
