# AI Living Codebase Synthesis

Inspired by LangChain's OpenWiki, OpenKB integrates an automated AI synthesis engine that scans your repository, extracts architectural context, and writes Google OKF-compliant concept documents.

## How It Works

<Steps>
  <Step title="1. Context & Evidence Gathering">
    OpenKB walks your file tree, extracts AST structures from primary entry files, and summarizes recent Git commit histories.
  </Step>
  <Step title="2. Gemini 3.7 Flash Synthesis">
    The gathered context is passed to **Google Gemini 3.7 Flash** (via OpenRouter) with strict OKF v0.2 system constraints.
  </Step>
  <Step title="3. OKF Concept Generation">
    Concept documents are written directly to \`content/\` (or \`openwiki/\`) with YAML frontmatter.
  </Step>
  <Step title="4. Agent Pointer Synchronization">
    OpenKB injects delimited pointers into \`AGENTS.md\` and \`CLAUDE.md\` so coding agents (Cursor, Claude Code, Copilot) automatically discover the knowledge base.
  </Step>
</Steps>

## Running AI Synthesis

Set your OpenRouter API key and execute the CLI generate command:

```bash
export OPENROUTER_API_KEY="sk-or-v1-..."
openkb generate --init
```

<Callout type="tip" title="Incremental Updates">
Use \`openkb generate --update\` in CI/CD pipelines (e.g. GitHub Actions) to incrementally update only the documentation affected by new git commits.
</Callout>
