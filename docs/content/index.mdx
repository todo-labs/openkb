# Welcome to OpenKB

**OpenKB** is an AI-native documentation engine built for modern software teams. It combines the developer experience of modern MDX with **Google's Open Knowledge Format (OKF v0.2)** and **OpenCode agentic codebase synthesis**.

<Callout type="tip" title="Dual-Audience by Design">
OpenKB generates sites that are visually stunning and interactive for human developers, while producing structured machine-traversable knowledge graphs for AI coding agents.
</Callout>

## Feature Highlights

<CardGroup cols={2}>
  <Card title="Google OKF v0.2 Specification" icon="shield-check" href="okf-spec/">
    Full YAML frontmatter with trust provenance, verification tracking, and concept graphs.
  </Card>
  <Card title="AI Living Codebase Synthesis" icon="bot" href="ai-synthesis/">
    Read-only OpenCode research sessions that ground documentation in inspected source files.
  </Card>
  <Card title="Interactive MDX Suite" icon="sparkles" href="components/">
    Rich components including synchronized Tabs, CodeGroups, Steps, Accordions, and ParamFields.
  </Card>
  <Card title="100% Static Export" icon="zap" href="quickstart/">
    Powered by Astro with zero-server requirements. Deploy to GitHub Pages, Cloudflare, or Vercel.
  </Card>
</CardGroup>
