## Accordions and Disclosures

<AccordionGroup>
  <Accordion title="How does static search work?">
    Search is powered by Pagefind, which indexes all rendered HTML at build time and executes queries entirely in the client browser with zero backend server overhead.
  </Accordion>
  <Accordion title="Can I customize the primary brand color?">
    Yes, edit \`colors.primary\` in \`docs.json\` with any hex color code. OpenKB automatically generates matching light and dark theme shades.
  </Accordion>
</AccordionGroup>
